# specs/

Qui vivono i documenti dello spec driven development. Li crea Cline con le skill `sdd-...`, li rivedi e approvi tu.

| File | Creato da | Contenuto |
|---|---|---|
| `interview.md` | `/sdd-interview` | risposte dell'intervista e dubbi aperti |
| `spec.md` | `/sdd-specify`, aggiornato da `/sdd-change` | user story, requisiti EARS (R1, R2...), casi limite |
| `plan.md` | `/sdd-plan`, aggiornato da `/sdd-change` | modello dati, servizi, componenti, scelte motivate |
| `tasks.md` | `/sdd-tasks`, aggiornato da `/sdd-implement` e `/sdd-change` | compiti T1, T2... con requisiti coperti e verifica |
| `verifica.md` | `/sdd-verify` (solo se lo chiedi) | tabella requisito, stato, evidenza |

Quando riusi il repo per un progetto nuovo, svuota questa cartella (tieni solo questo README).
