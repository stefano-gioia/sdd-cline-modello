# specs/

Qui vivono i documenti dello spec driven development. Li crea Cline con i workflow, li rivedi e approvi tu.

| File | Creato da | Contenuto |
|---|---|---|
| `interview.md` | `/interview.md` | risposte dell'intervista e dubbi aperti |
| `spec.md` | `/specify.md`, aggiornato da `/change.md` | user story, requisiti EARS (R1, R2...), casi limite |
| `plan.md` | `/plan.md`, aggiornato da `/change.md` | modello dati, servizi, componenti, scelte motivate |
| `tasks.md` | `/tasks.md`, aggiornato da `/implement.md` e `/change.md` | compiti T1, T2... con requisiti coperti e verifica |
| `verifica.md` | `/verify.md` (solo se lo chiedi) | tabella requisito, stato, evidenza |

Quando riusi il repo per un progetto nuovo, svuota questa cartella (tieni solo questo README).
